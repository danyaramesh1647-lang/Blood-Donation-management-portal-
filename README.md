 LifeDrop – Blood Donation Management Portal

LifeDrop is a responsive frontend web application designed to make blood donation and blood-request activities easier to manage through a simple and user-friendly interface.

The project provides separate sections for registering blood donors, finding donors, requesting blood, viewing blood availability, and exploring blood donation camps.

📌 Project Overview

Blood donation plays an important role in supporting patients during emergencies, surgeries, and medical treatments. LifeDrop provides a digital interface that connects potential donors and blood seekers through an organized blood donation portal.

This project is developed as a Frontend Web Technologies project using HTML, CSS, and JavaScript.

«Note: This is an academic frontend project. The donor, blood availability, and camp information displayed in the application are demo/sample data and are not connected to a real medical or blood-bank database.»

🖥️ Main Modules

1. Home Page

Provides an overview of the portal with quick access to donor registration, donor search, and blood requests.

2. Donor Registration

Allows users to enter basic donor information such as:

- Name
- Age
- Gender
- Blood group
- Contact details
- Location
- Last donation date
- Availability

3. Find a Donor

Users can search for available donors based on:

- Blood group
- Location
- Availability

4. Blood Request

Provides a form for submitting a blood requirement with details such as patient name, required blood group, hospital, location, units required, and contact information.

5. Blood Availability

Displays sample blood-stock information for different blood groups in a simple dashboard format.

6. Donation Camps

Displays upcoming blood donation camps with information such as date, venue, time, and registration options.

📱 Responsive Design

LifeDrop is designed to work across different screen sizes.

The interface adapts to:

- 📱 Mobile phones
- 📲 Tablets
- 💻 Laptops
- 🖥️ Desktop screens

CSS media queries are used to create a mobile-friendly layout.

🚀 How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Navigate through the different sections using the navigation menu.

No backend server or database is required for the current frontend version.
